# paper-workbench 快速上手与跨机迁移

## 三层心智模型（先建立这个，后面全通）

| 层 | 是什么 | 住在哪 | 怎么流转 |
|---|---|---|---|
| 框架 | 9 个斜杠命令、模板、解析工具链 | GitHub 仓库 paper-workbench → 每台机器的用户目录 | git clone + install.sh，每台机器装一次 |
| 数据 | 论文 PDF、解析稿、笔记、概念卡、台账、学习者档案 | 你的工作台目录（本身是 Obsidian 仓库） | Obsidian Sync，一条通道管同步+历史 |
| 本地环境 | 解析 venv、MCP 配置（含机器路径） | 工作台里的 `.zcode/` 点目录 | 不流转，每台机器由 /paper-init 重建 |

## 一、初次使用怎么开始

### 第 1 步：机器准备（一次性，约 10 分钟）

1. 装 ZCode（或 Claude Code / DeepSeek Harness 任一宿主；下文以 ZCode 为例）
2. 装 [uv](https://docs.astral.sh/uv/)（Python 版本管理，Windows 一条命令：`powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`）
3. 推荐：装 Obsidian 并开通 Obsidian Sync（不开也能用，只是没有跨机同步与图形界面）

### 第 2 步：装框架（一次性，每台机器）

```bash
git clone https://github.com/LessXi/paper-workbench
cd paper-workbench
bash install.sh        # Windows: powershell -ExecutionPolicy Bypass -File install.ps1
```

装完**重开一个 ZCode 会话**，输入 `/` 能看到 9 个 paper-* 命令。

### 第 3 步：生成你的工作台（一次性）

选一个目录（建议数据盘，如 `D:\Research\paper-lab`），用 ZCode 打开它作为工作区，说：

```
/paper-init
```

它会：问你的研究方向（决定检索用词与精读侧重）→ 建数据骨架（library/、概念卡/、台账等）→ 在 `.zcode/` 建解析环境（加 `--lite` 可秒级安装，默认含 MinerU，模型首次解析时才下载）→ 写 MCP 配置（arxiv + paper-search 学术检索）→ 提示你在 Obsidian 里「打开文件夹作为仓库」。

### 第 4 步：开始用

```
/paper-find <你的主题>      # 多源检索 → 分档初筛 → 下载落库登记
/paper-read <论文>          # AI 代读出完整笔记（快速筛选用）
/paper-learn <论文>         # 学习模式：导读地图 → 你读你复述 → AI 纠错出题 → 你写复现 AI review
/paper-lab                  # 随时盘点进度
```

用 Obsidian Sync 的：直接开，**无需排除任何目录**（`.zcode/` 点开头，Obsidian 自动不碰）。

## 二、换一台机器怎么无缝迁移

前提：旧机器上工作台已通过 Obsidian Sync 同步（如果没有，先在旧机器 Obsidian 里把工作台设为仓库并开 Sync，等上传完）。

新机器四步：

1. **装机器级依赖**：uv、ZCode、Obsidian（登录同一账号）
2. **等数据落盘**：Obsidian Sync 把工作台目录拉下来（PDF 大文件后到，可边等边做第 3 步）
3. **装框架**：同"初次使用"第 2 步（clone + install.sh）
4. **恢复**：在同步好的工作台目录打开 ZCode，说 `/paper-init`——它检测到已有台账与论文，自动进**恢复模式**：不碰数据，只重建本机 `.zcode/`（解析环境、MCP 配置），然后对照台账逐条校验并汇报缺口（缺 PDF 多半是还在同步，等即可）

恢复完成的标志：`/paper-lab` 盘点一切正常。你的学习者档案（learner-profile.md）也在同步范围内，AI 对你的了解跟着走。

### 会跟过去 / 不会跟过去的

- **跟过去**：全部论文数据与知识资产（这是 Obsidian Sync 的职责）
- **不跟、自动重建**：`.zcode/` 本地环境（每台机器独立）
- **框架命令**：走 GitHub，每台机器装一次，全世界同一版本

### 双机并存注意

Obsidian Sync 会自动处理冲突（保留冲突副本），但最省心的用法是同一时段只在一台机器上编辑。两台机器的 `.zcode/` 互不相干，各自运行。
