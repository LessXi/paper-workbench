# paper-workbench 快速上手与跨机迁移

## 三层心智模型（30 秒）

| 层 | 是什么 | 住在哪 | 怎么流转 |
|---|---|---|---|
| 框架 | 9 个斜杠命令、模板、解析工具链 | GitHub 仓库 paper-workbench → 机器用户目录 | 插件市场装（或 bootstrap 单命令），每台机器装一次 |
| 数据 | 论文 PDF、解析稿、笔记、概念卡、台账、学习者档案 | 你的工作台目录（本身是 Obsidian 仓库） | Obsidian Sync，一条通道管同步+历史 |
| 本地环境 | 解析 venv、MCP 配置（含机器路径） | 工作台里的 `.zcode/` 点目录 | 不流转，每台机器由 /paper-init 重建 |

一句话：**数据走 Sync，框架走 GitHub，环境就地重建。**

## 一、初次使用（两步）

**① 装框架**：ZCode 里 设置 → 插件管理 → Discover → **+** 从 GitHub 添加 `https://github.com/LessXi/paper-workbench` → 安装 → 重开会话。
（DSH 用户：`dsh plugin --profile web add github:LessXi/paper-workbench`，装完多一个 `paper` 工具；其他 terminal 用户：跑 README 里的 bootstrap 单命令）

**② 说 `/paper-init`**：在任意你想当工作台的目录（建议数据盘）。它只问一个问题——解析环境档位：

| 档位 | 安装耗时 | 能拿到什么 | 适合 |
|---|---|---|---|
| **lite** | 秒级 | 纯文本（公式乱码、无表格无图） | 筛论文、扫摘要 |
| **full** | 首次约十来分钟（依赖+模型下载，之后正常） | 公式→LaTeX、表格→markdown、全部图表 | 精读、学习模式、复现 |

犹豫就先 lite——随时一条命令升级（用到时 parse_paper.py 会提示）。其余全自动：研究方向默认 AI/ML（AGENTS.md 里可改）、uv 缺了自动装、骨架/MCP/Obsidian 注册一并做好。

之后：`/paper-find <主题>` 检索落库 → `/paper-learn <论文>` 学透（或 `/paper-read` 让 AI 代读筛选）→ `/paper-lab` 看进度。用 Obsidian Sync 的直接开，无需排除任何目录。

## 二、换一台机器（两步）

前提：旧机器上工作台已在 Obsidian Sync 里（还没开就先开，等上传完）。

**① 新机器装框架**：同上（市场安装或 bootstrap），Obsidian 登录同一账号等 Sync 把数据拉下来（PDF 后到，可边等边装框架）。

**② 说 `/paper-init`**：它认出已有台账，自动进**恢复模式**——不碰数据，按 AGENTS.md 记录的档位重建本机 `.zcode/`，对照台账逐条校验并汇报缺口（缺 PDF 多半还在同步路上）。`/paper-lab` 正常即恢复完成，学习者档案也跟着走。

双机并存：同一时段只在一台机器上编辑最省心；两台机器的 `.zcode/` 各自独立互不影响。
