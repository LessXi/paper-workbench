# /paper-survey：主题综述

输入：`$ARGUMENTS`。产出目录 `topics/<主题slug>/`。

## 1. 广撒网（目标 15-30 篇）

- `paper-search` MCP `search_papers` + `arxiv` MCP `search_papers`（多组关键词覆盖 AGENTS.md `research_fields` 的各方向；无 MCP 时用宿主网页检索兜底）
- 对 2-3 篇种子论文跑 `/paper-cite` 式引文扩展（奠基作与近期综述靠引用链补全）
- WebSearch 补充：Papers with Code 榜单、近届顶会相关 track

## 2. 精选（8-15 篇核心）

入选配额：奠基作（1-3）/ 主线演进（4-8）/ 当前最优或工业实践（1-3）/ 有价值的批判或负结果（0-1）。
说明每篇入选理由，呈现清单给用户确认后再深读。

## 3. 深读与综合

对核心篇目做快速精读（摘要+方法+主表，不必全文三遍），然后综合：

- **演化时间线**：按年份排列，标注每篇的核心增量（解决了前人的什么缺陷）
- **方法族谱**：把方法分成 2-4 个流派/家族，说明分野维度（如：精度优先 vs 延迟优先）
- **对比矩阵**：| 论文 | 年份 | 流派 | 核心思想 | 关键指标 | 数据集/平台 | 开源 | 局限 |
- **开放问题**：3-5 个当前未解决/值得用户切入的点（结合 AGENTS.md `research_fields` 背景）

## 4. 落盘

1. `topics/<主题>/survey.md`：完整综述（上述四部分）
2. 概念图：用 json-canvas 技能生成方法族谱 canvas，直接写入 PaperVault `方法图谱/<主题>.canvas`，节点链接对应论文笔记
3. 核心篇目中尚未落库的批量落库（PDF 下载 + registry 登记，状态`待读`，便于日后深读）
4. 未入选但检索到的相关文献列入 survey.md 附录"边缘相关文献"表

## 5. 汇报

综述核心结论（3-5 条）+ 族谱划分逻辑 + 最值得精读的 3 篇 + 开放问题。
