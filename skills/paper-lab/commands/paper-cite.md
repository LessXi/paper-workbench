# /paper-cite：引文图谱

输入：`$ARGUMENTS`。定位论文（registry / library / 直接 arXiv ID）。

## 1. 引文获取

用 `arxiv` MCP：

- `citation_graph`：后向引用（本文引用了谁 = 思想源头）与前向引用（谁引用了本文 = 影响与后续）
- 非 arXiv 论文改用 `paper-search` 的 Semantic Scholar 检索获取引用数据，或 WebSearch 兜底

## 2. 分析

- **思想源头**：被本文引用且被引量高的奠基文献（方法基础）
- **直接后续**：前向引用中方法直接改进/应用的工作
- **必读邻居**：综合前向+后向，挑 3-8 篇对理解本文最关键的文献，说明每篇"为什么必读"（一句话）
- **演化判断**：本文在脉络中的位置（开创/改进/应用/综述）

## 3. 落盘

1. `export_citations` 的 BibTeX（本文 + 必读邻居）追加到 `refs.bib`（去重：先检查是否已存在）
2. 必读邻居中值得跟进的，登记 `registry.md`（状态`待读`，评分按紧迫度）
3. 若该论文已有 notes.md：在笔记"开放问题"前插入 `## 引文脉络` 小节（源头→本文→后续，一条线各一句话）

## 4. 汇报

引文网络概览（文字描述脉络）+ 必读邻居清单及理由 + 已登记/已入库内容。
